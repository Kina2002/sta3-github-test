# 📋 기획서 (PRD) : 화학공학 전공 취업 준비 트래커

> "무엇을, 왜, 어떻게 만들지"를 한 장에 정리한 문서입니다.
> Codex는 작업할 때 이 문서를 설계도로 참고합니다.

작성일: 2026-09-15
작성자: 화학공학 전공 / QA·QC·품질관리 관심

---

## 1. 풀고자 하는 문제

- **지금은 이렇게 해요 (현재 방식):** 관심 산업의 뉴스와 품질 관련 자료를 Notion `new-letter` 데이터베이스에 모으기 시작했다.
- **이게 불편해요 (문제점):** 산업 공부 자료, 회사 정보, 채용공고, 실제 지원 기록이 구분되지 않아 공고별 준비 상황과 회사 공부 내용을 연결하기 어렵다.
- **이렇게 되면 좋겠어요 (이상):** 전국의 접근 가능한 지역에서 화학·고분자·소재·화장품·배터리·반도체 관련 QA·QC 공고를 찾고, 회사와 업종을 공부한 내용부터 지원 결과까지 한곳에서 이어서 관리한다.

---

## 2. 사용자

- **누가 쓰나요?** 취업을 준비하는 참가자 본인
- **언제 쓰나요?** 새 공고를 찾을 때, 지원서를 작성할 때, 면접을 준비하거나 결과를 회고할 때
- **어디서 쓰나요?** 개인 Notion 작업 공간과 Codex

---

## 3. 입력 자료

- **사용할 파일 또는 입력 내용:** 기업 공식 홈페이지, 공식 채용 페이지, 신뢰할 수 있는 채용공고, 산업 뉴스, 참가자의 이력서와 자기소개서
- **반드시 필요한 항목:** 회사명, 공고명, 공식 링크, 마감일, 근무지, 담당 업무, 필수·우대 조건
- **개인정보나 민감 정보 포함 여부:** 이력서와 지원서에는 개인정보가 포함될 수 있으므로 외부 게시나 전송 전에 참가자가 확인한다.
- **아직 없는 자료:** 참가자의 이력서, 희망 연봉과 기업 규모 우선순위

---

## 4. 핵심 기능 (MVP) : 이것만 되면 일단 성공

1. `company-list`에서 회사의 산업·업종·제품·기술·품질 특징을 정리한다.
2. `job-posting`에서 현재 지원 가능한 공고의 링크·마감일·근무지·요구 조건을 관리한다.
3. `application`에서 공고별 지원 상태, 사용 문서, 결과와 회고를 기록한다.
4. 회사 → 공고 → 지원 기록을 서로 연결한다.
5. 전국을 대상으로 검색하되 이동이 어려운 섬과 오지는 우선 제외하고, 애매한 지역은 참가자가 확인하도록 표시한다.

- **AI에게 맡길 것:** 자료 검색, 공고 정보 추출, 회사·업종 요약, 요구 역량 비교, 초안과 면접 질문 작성
- **사람이 확인할 것:** 관심 여부, 지역 접근성, 지원 결정, 개인정보와 최종 문장, 실제 지원서 제출

---

## 5. 결과와 완료 조건

- **결과물과 저장 위치:** Notion `STA 3기` 아래 회사·채용공고·지원 데이터베이스, GitHub 저장소의 이 기획서와 작업 기록
- **어떤 입력이면 어떤 결과가 떠야 하는가:** 유효한 공식 공고를 찾으면 회사·직무·근무지·마감일·요구 조건과 원문 링크가 저장되고 관련 회사 기록과 연결된다.
- **실패하면 무엇이 보여야 하는가:** 마감 여부나 위치가 불확실하면 추측하지 않고 `확인 필요`로 표시하며, 섬·오지이거나 마감된 공고는 저장하지 않거나 제외 이유를 남긴다.

---

## 6. 나중에 추가할 것 (지금은 안 만듦)

- 새 공고를 정기적으로 확인하는 자동화와 알림
- 이력서·자기소개서 버전별 적합도 비교
- 면접 일정과 후속 연락 알림
- 지원 결과를 산업·직무별로 비교하는 통계 화면

---

## 7. 만드는 방식과 공유 방법

- [x] **일회성** : Codex가 요청할 때 최신 공고를 검색하고 Notion에 정리
- [ ] **자동화** : 내가 안 봐도 정기적으로 공고 확인
- [ ] **도구·웹** : 별도 취업 관리 웹페이지

선택: 일회성 Notion 도구 / 이유: 지금은 검색 기준과 실제로 유용한 항목을 먼저 확인하는 단계이기 때문이다.

**다 되면 어떻게 전달하나:** 참가자는 Notion 데이터베이스에서 결과를 확인하고, 설계와 변경 기록은 GitHub Pull Request에서 검토한다.
