# 지원서 작성·지원 현황 화면 분리

- 기준일: 2026-09-15
- 브랜치: `feature/application-pages-split`
- 요청: 공고 페이지 안에서 찾기 어려운 지원서 내용과 지원 진행 상태를 각각 별도 화면으로 분리

## 개선 후보와 선택

1. `지원서 작성`과 `지원 현황`을 별도 화면으로 분리
2. 기존 화면은 유지하고 홈에 바로가기만 추가
3. 두 기능을 하나의 통합 대시보드에 배치

사용자가 두 화면을 따로 만들어 달라고 요청했으므로 1번을 적용했다. 작성할 내용과 진행 상태를 분리하면 자기소개서 작성 중에는 질문과 경험 연결에 집중하고, 일정 확인 중에는 다음 행동만 빠르게 볼 수 있다.

## 만든 화면

### 지원서 작성

- 주소: https://app.notion.com/p/abc2abab775c4b4ea3906e53ef0b0732
- 데이터 원본: `collection://5f16892a-e289-40e0-a480-1bd1006e190f`
- 주요 표시 항목: 지원서명, 회사, 마감일, 작성 상태, 다음 할 일
- 보관 내용: 제출항목, 자기소개서 질문, 문항 조건, 추천 소재, 문항별 추천 소재와 전체 지원 준비 묶음

기존 우일씨앤텍 QC 묶음을 `우일씨앤텍 QC 지원서`로 옮겨 첫 사용 예시를 만들었다. 본문에는 회사 업종, 공고 핵심, 지원 가치, 지원 전 확인, 경험 연결표, 자기소개서 핵심, 예상 면접 질문과 답변 방향, 제출 전 확인 목록을 유지했다.

### 지원 현황

- 주소: https://app.notion.com/p/3dcf2f0727e8819bb25ace879ff8a88f
- 연결 원본: `collection://5063a06c-0258-4bfa-a6a0-959eeb9ce31a`
- 주요 표시 항목: 지원 기록, 회사, 채용공고, 상태, 다음 일정, 다음 할 일

기존 지원 기록을 새로 복사하지 않고 연결 보기로 표시했다. 따라서 원래 지원 상태를 수정하면 이 화면에도 같은 내용이 보인다.

## 함께 바꾼 것

- 홈 화면에 `✍️ 지원서 작성`, `📮 지원 현황` 바로가기를 추가했다.
- 취업 업데이트 센터의 `지원서 업데이트` 흐름을 새 `지원서 작성` 화면 기준으로 수정했다.
- `career-update-center`, `job-application-pack` 스킬이 지원서 작성 결과와 지원 현황을 구분하도록 수정했다.
- 실제 제출을 확인하지 않은 기록은 지원 완료로 바꾸지 않는 원칙을 유지했다.

## 시행착오와 배움

- 일반 페이지 본문에 데이터 원본을 마크다운 태그로 직접 넣었을 때 `Data source not found`가 발생했다. 원본 자료는 변경되지 않았으며, Notion의 연결 보기 생성 기능을 사용하니 기존 데이터를 안전하게 한 화면에 표시할 수 있었다.
- 지원서 예시를 처음 만들 때 본문 안의 백틱이 실행 문법과 충돌했다. 실행 전에 실패해 중복 페이지가 생기지 않은 것을 확인하고 일반 강조로 바꿔 한 번만 생성했다.
- 작성 정보와 진행 정보를 한 표에 모두 넣으면 열이 많아져 읽기 어려워진다. 화면 목적에 맞춰 보이는 열을 줄이고, 상세 정보는 행을 열었을 때 확인하는 구성이 더 적합하다.

## 확인 방법

홈 화면에서 `✍️ 지원서 작성`을 열면 우일씨앤텍 QC 지원서가 보이고, 그 행을 열면 전체 지원 준비 묶음을 확인할 수 있다. `📮 지원 현황`을 열면 기존 지원 기록의 상태·다음 일정·다음 할 일이 바로 보인다.
