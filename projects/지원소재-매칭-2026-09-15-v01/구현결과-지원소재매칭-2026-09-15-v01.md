# 지원 소재 재사용·지원서 업데이트 기능

## 목표

공고마다 지원 준비 묶음을 처음부터 반복 작성하지 않고, 사용자가 한 번 정리한 역량·경험·활동을 자기소개서 문항과 공고 요구에 맞춰 재사용한다.

## 입력과 결과

1. 사용자는 내 지원 소재 보관함에 상황, 행동, 결과와 근거, 장비·도구를 적는다.
2. 사용자는 공고에 지원서 제출항목, 자기소개서 질문, 문항 조건을 적고 `지원서 업데이트 필요`를 선택한다.
3. `지원서 업데이트` 요청을 받으면 공고 질문과 소재를 비교한다.
4. 결과는 연결된 지원 기록에 전체 지원 준비 묶음으로 작성한다.

지원 준비 묶음은 회사 업종, 공고 핵심, 지원 가치, 지원 전 확인사항, 경험 연결표, 자기소개서 핵심, 예상 면접 질문과 답변 방향, 제출 전 확인 목록을 포함한다.

## 데이터베이스 변경

### job-posting

- 지원서 제출항목
- 자기소개서 질문
- 문항 조건
- 지원서 업데이트 필요

### application

- 문항별 추천 소재
- 추천 소재 관계
- 소재 매칭 상태

### 내 지원 소재 보관함

- 소재 제목, 경험 유형, 핵심 역량, 직무 연결, 산업 연결
- 상황, 내 행동, 결과·근거, 사용 장비·도구
- 활용 상태, 대표 소재, 수정일

## 업데이트 명령

- 지원서 업데이트
- 내 소재 업데이트
- 공고 업데이트
- 뉴스 업데이트
- 전체 업데이트

`전체 업데이트`는 공고, 추천 순위, 내 소재, 지원서, 뉴스 순서로 진행한다. 뉴스레터 발행은 기존 규칙대로 Notion 검증 후 Slack `#산업뉴스레터`에 공유한다.

## 사실 보호

- 사용자 소재와 공식 공고에 없는 수치·역할·장비 운용 경험은 만들지 않는다.
- 불명확한 내용은 `확인 필요`로 남긴다.
- 지원서 제출과 개인정보 전송은 자동으로 하지 않는다.
- 기존 우일씨앤텍 지원 준비 묶음은 예시 자료로 보존한다.
